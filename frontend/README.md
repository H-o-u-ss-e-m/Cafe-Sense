# 🎨 Frontend Web App

Ce dossier accueillera l'interface utilisateur web pour le café intelligent :
- Affichage du flux vidéo de la caméra PC avec détection en temps réel (tables libres, occupées, chronomètres).
- Tableau de bord des tables (statut en direct).
- Interface interactive de discussion avec l'Agent IA (Menu, Tarifs, Recommandations, Photos de plats/cafés).
