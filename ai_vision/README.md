# 👁️ Vision par Ordinateur - Détection Tables & Clients

- `models/` : Contient les poids entraînés (`best.pt`, `best.onnx`, `yolov8n.pt`, `yolov8n.onnx`).
- `notebooks/` : Notebooks Google Colab d'entraînement (`Entrainement_Modele_Cafe_Colab.ipynb`).
- `cafe_monitor_v2.py` : Moteur de suivi temps réel (IoU, filtrage anti-parquet, chronomètres dynamiques).
- `test_local.py` : Script de test rapide sur webcam ou fichier vidéo.
